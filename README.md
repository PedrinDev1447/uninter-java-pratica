# Baozi Store API 

API desenvolvida como parte da atividade prática da disciplina de Programação de Sistemas da **UNINTER**. O projeto consiste em um sistema de gerenciamento para uma loja fictícia de Baozi (pãezinhos orientais no vapor).

##  Tecnologias Utilizadas
- **Java 17** ou superior
- **Spring Boot 3.x**
- **Spring Data JPA** (Persistência de dados)
- **H2 Database** (Banco de dados em memória para testes)
- **Maven** (Gerenciador de dependências)

##  Funcionalidades (CRUD)
A API permite o gerenciamento completo de:
- **Clientes:** Cadastro e consulta de usuários.
- **Produtos:** Cadastro de itens do cardápio com preço e controle de estoque.
- **Pedidos:** Registro de vendas vinculando clientes e produtos.
